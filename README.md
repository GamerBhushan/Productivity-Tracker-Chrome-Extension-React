## 🚀 Features

- ⏳ Track time spent on specific websites.
- 🎯 Set daily productivity goals.
- 📊 View insights and productivity trends.
- ⚡ Built with **React, TypeScript, Vite & Bun**.
- 🖥️ Works seamlessly in the Chrome browser.

---

## ⚡ Tech Stack

- **Frontend:** React + Vite + TypeScript
- **Build Tool:** Bun
- **Storage:** Chrome Storage API
- **Permissions:** Chrome Extensions API

## 🛠️ Installation & Setup

Follow these steps to install and use the Chrome extension:

### 1 **Clone the Repository**
```sh
npm install -g bun
git clone https://github.com/GamerBhushan/Productivity-Tracker-Chrome-Extension-React.git
cd Productivity-Tracker-Chrome-Extension-React
```

### 2 **Install Dependencies**
```sh
bun install  
```

### 3 **Build the Extension**
```sh
bun run build
```

### 4 **Load the Extension in Chrome**
1. Open **Google Chrome** and navigate to `chrome://extensions/`
2. Enable **Developer Mode** (toggle in the top-right corner).
3. Click **Load Unpacked** and select the `dist` folder inside the project.
4. The extension will be added to Chrome!
